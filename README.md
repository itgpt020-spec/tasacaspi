# 🌊 ТазаКаспий — экотрекер Атырау

Telegram-бот + веб-сайт для народного мониторинга уборок и свалок в Атырау.

## Возможности

### 🤖 Telegram-бот
- 🧹 **«Я убрал мусор»** — пошаговый ввод: фото → геолокация → название места → тип мусора (пластик, стекло, металл, бумага, бытовой, строительный) → вес и количество мешков. Можно добавить несколько типов за одну уборку.
- 📍 **«Здесь свалка»** — отметить новое место загрязнения с геолокацией и фото.
- 📊 **Статистика** — общий сбор по типам мусора и по месяцам.
- 🏆 **Рейтинг** — топ волонтёров по собранным килограммам.

### 🌐 Веб-сайт
- Интерактивная карта Атырау с двумя слоями:
  - 🟢 **Зелёные точки** — убранные участки
  - 🔴 **Красные точки** — свалки, требующие уборки
- Дашборд с цифрами: всего кг, уборок, свалок, волонтёров
- Графики: динамика по месяцам (столбчатый), распределение по типам мусора (круговая)
- Топ волонтёров и рейтинг групп / команд

## Установка

```bash
pip install -r requirements.txt
```

Настройте `config.py`:
- `BOT_TOKEN` — от @BotFather
- `MAP_CENTER_LAT / LON` — координаты центра карты (по умолчанию Атырау)

Запуск:
```bash
# Терминал 1 — бот
python bot.py

# Терминал 2 — сайт
python webapp.py
```

Сайт: http://localhost:5000

## Структура

| Файл | Описание |
|------|----------|
| `config.py` | Токены, координаты, справочник типов мусора |
| `database.py` | SQLite: пользователи, уборки, позиции, свалки |
| `bot.py` | Telegram-бот (aiogram 3) с FSM-сценариями |
| `webapp.py` | Flask + дашборд с Leaflet.js и Chart.js |

## Для преподавателя / методиста

Этот проект демонстрирует:
- Работу с геоданными (геолокация Telegram + Leaflet)
- Многошаговые сценарии в боте (Finite State Machine)
- Сложные INSERT с транзакционной логикой (уборка → позиции → пересчёт статистики)
- Агрегирующие SQL-запросы (GROUP BY, SUM, COUNT)
- Интеграцию бота и веба через единую БД
